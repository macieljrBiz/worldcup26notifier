# Quick Reference for WorldCupNotifier Development

## Current Project State
- **Language**: C# (.NET 8.0 WPF)
- **Target**: Windows 10.0.19041.0+
- **Purpose**: Monitor FIFA World Cup matches, send Windows toast notifications
- **Data Source**: football-data.org REST API
- **Settings Storage**: `%APPDATA%\WorldCupNotifier\settings.json`

## Architecture Quick Map

### Data Flow: Settings → Polling → Event Detection → Notifications
```
User Input (UI)
    ↓
SaveSettings() → JSON file
    ↓
CheckLiveDataAsync()
    ↓
FetchMatchesAsync() → football-data.org
    ↓
DetectEvents() → Compare MatchSnapshot objects
    ↓
Add to Feed + SendNativeNotificationAsync()
    ↓
AddFeedItem() + DesktopNotificationService.ShowToast()
```

## Common Code Patterns

### Adding a New Feature

**Pattern: New Alert Type**
1. Add checkbox in MainWindow.xaml (Configuration section)
2. Add bool property to AppSettings class
3. Update SaveSettings() and ApplySettingsToUi()
4. Create DetectXxxEvents(Match, MatchSnapshot, MatchSnapshot?) method
5. Call from DetectEvents() loop

**Pattern: UI State Update**
```csharp
SetStatus("Status Title", "Detailed message");
AddFeedItem("Alert Title", "Alert message");
```

**Pattern: Async Button Handler**
```csharp
private async void ButtonName_Click(object sender, RoutedEventArgs e)
{
    SaveSettings();
    Button.IsEnabled = false;
    try
    {
        await SomeAsyncOperation();
    }
    catch (Exception ex)
    {
        SetStatus("Error", ex.Message);
        AddFeedItem("Operation Failed", ex.Message);
    }
    finally
    {
        Button.IsEnabled = true;
    }
}
```

**Pattern: Event Detection**
```csharp
private IEnumerable<DetectedEvent> DetectXxxEvents(
    Match match, 
    MatchSnapshot snapshot, 
    MatchSnapshot? previous)
{
    if (!_settings.NotifyXxx)
        yield break;
    
    if (/* condition for event */)
    {
        yield return new DetectedEvent(
            $"{match.Id}-xxx-{snapshot.Status}",
            "User-facing title",
            "Detailed message");
    }
}
```

**Pattern: Settings Access**
```csharp
if (string.IsNullOrWhiteSpace(_settings.ApiKey))
{
    SetStatus("Missing API key", "Add your football-data.org API key.");
    return;
}
```

## Debugging Tips

### Check Settings Persistence
```csharp
// Settings file location:
var settingsPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData),
    "WorldCupNotifier",
    "settings.json");
// Open in any text editor to inspect
```

### Verify API Connectivity
1. Click "Check live data now" button
2. Check feed for API error messages
3. Verify API key validity at football-data.org dashboard
4. Check internet connectivity

### Test Toast Notifications
1. Click "Send test notification" button
2. Look for Windows notification in system tray
3. Check feed for success/failure message
4. Verify "Enable native Windows notifications" checkbox is checked

### Trace Polling Behavior
1. Observe "Polling started" / "Polling stopped" messages in status
2. Check timestamp in "Last checked" detail
3. Verify polling interval in PollingIntervalSeconds field (min 70)
4. Monitor feed for new alerts during polling

## Common Issues & Solutions

| Issue | Cause | Solution |
|-------|-------|----------|
| Settings not saved | Forgot to click "Save settings" | Always SaveSettings() before async ops |
| No notifications appear | NotificationsEnabled checkbox unchecked | Check Configuration > Enable checkbox |
| No notifications appear | No valid favorite team | Select or type team name, save |
| API error 429 | Rate limit exceeded | Increase PollingIntervalSeconds (min 70) |
| API error 401 | Invalid API key | Verify key at football-data.org |
| Duplicate notifications | Multiple events detected for same match state | Event ID deduplication should prevent this |
| UI freezes during poll | Forgot await or blocking call | Ensure FetchMatchesAsync uses await |
| Toast doesn't appear | Notifications disabled in Windows Settings | Check Windows > Settings > System > Notifications |

## Naming Conventions Reference
- Private fields: `_underscore` prefix
- Public properties: `PascalCase`
- Public methods: `PascalCase`
- Local variables: `camelCase`
- Event handlers: `ControlName_Action` (e.g., `SaveButton_Click`)
- Constants: `UPPER_CASE` (rare in this project)
